# SYNOPSIS

    bfgdata.pl OPTIONS

# OPTIONS

You must specify one of --help, --ships, --images, --extract-to.

- --help - show help.
- --ships - generate ship profiles in the current directory.
- --images - generate ship images in the current directory.
- --extract-to=DIR - extract images from the Fleets book into `DIR` for later use.
- --image-SRC=DIR - use the images in `DIR` instead of extracting them from the Fleets book.
